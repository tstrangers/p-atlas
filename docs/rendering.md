# 渲染与交互

## 球面星图

`app.js` 以黄金角将图片均匀分布在球面上，在 Canvas 2D 内完成旋转与透视投影。选中时沿较短角度平滑转向正面，停止自转，保留光雾播放；关闭详情后恢复原播放状态。

同 P 连线以线性青紫渐变绘制，流光随独立相位移动；并不运行语义嵌入或相似度模型。

## 烟雾与扩散

`aura.js` 是项目原创的 WebGL 实现。沿视线对球内密度场多次采样，累积散射与吸收，再做辉光和曝光压缩。三个移动源具有不同强度，各自随机出生时间，发出地形等高线状的扭曲波纹。交接处用平滑最小距离融合，避免硬切或叠加过曝。

选中星点居中后，加入更强的第四个源，只从当前选择时刻开始发波。暂停冻结所有动画时钟；减少动态效果时不执行持续动画。

支持时使用 16 位浮点中间纹理；不支持时回退至低精度纹理并加入微量静态抖动，以减轻暗部色带。WebGL 不可用时保留 CSS 柔光后备效果。实际速度随设备、浏览器和电源状态变化。

## 背景与分层

公开版 `shards.js` 是独立的 Canvas 折面粒子背景，具有流动路径、透视缩放、旋转和正反面亮度。球体后方是不透明圆形遮罩，随球心与缩放同步更新，防止星屑从烟雾内透出。

星图画布覆盖整页，放大后可连续绘制到透明标题栏下方，仅在视口边缘裁切。所有图片与 UI 保持清晰，不参与烟雾的后处理模糊。

## 性能边界

星图使用按需缩略图缓存；背景有像素预算；烟雾有分辨率和采样上限及自适应调整。它是视觉化收藏浏览器，不是大规模通用图数据库。大量增加节点和连线前，应先测量实际设备负载。
